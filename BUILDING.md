# Building FinVault Yuri from Source

This guide explains how to compile, sign, and test **FinVault Yuri** (`com.yuri.finvault`) completely on your own from source code—using **CodeAssist** (Mobile or Windows Desktop) or a standard **Android Studio** Compose project.

---

## Project Architecture & Requirements

**FinVault Yuri** uses **CodeAssist's native build configuration (`app/module.toml`)** rather than Gradle files. All application logic and custom Canvas icons live in a single Kotlin source file with **zero third-party library dependencies** beyond Jetpack Compose and Material 3.

| Setting | Value |
| :--- | :--- |
| **Package / Namespace** | `com.yuri.finvault` |
| **Primary Source File** | `app/src/main/kotlin/com/yuri/finvault/MainActivity.kt` |
| **Build Configuration** | `app/module.toml` |
| **Minimum Android SDK** | API 26 (Android 8.0 Oreo) |
| **Compile / Target SDK** | API 36 (Android 16) |
| **Core Dependencies** | `kotlin-stdlib`, `androidx.activity:activity-compose`, `androidx.compose.ui:ui`, `androidx.compose.foundation:foundation`, `androidx.compose.material3:material3` |

> **Important:** Never place a second copy of `MainActivity.kt` inside `app/src/main/java/`. Keep all Kotlin code inside `app/src/main/kotlin/com/yuri/finvault/MainActivity.kt` to avoid Kotlin redeclaration errors.

---

## Method 1: Build on Android Phone (CodeAssist Mobile)

This is the fastest way to compile **FinVault Yuri** directly on an Android device.

### Step 1: Create a Base Project in CodeAssist
1. Install and open **CodeAssist** on your Android device.
2. Create a new **Jetpack Compose (Empty Activity)** project:
   - **Project Name:** `finvault`
   - **Package Name:** `com.yuri.finvault`
   - **Language:** Kotlin
   - **Min SDK:** 26
3. Wait for CodeAssist to generate the project folder (including its hidden `.platform/` metadata directory).

### Step 2: Replace the Source & Resources
1. Download or clone this repository:
   ```bash
   git clone https://github.com/YuriRinkashime/FinVault.git
   ```
2. Copy the repository's `app/` folder over the `app/` folder inside your newly created CodeAssist project (keeping CodeAssist's `.platform/` folder intact).
3. Delete any template `app/src/main/java/` directory generated by CodeAssist so only `app/src/main/kotlin/com/yuri/finvault/MainActivity.kt` exists.
4. Open `app/module.toml` and verify:
   - `namespace = "com.yuri.finvault"`
   - `minSdk = 26`
   - `compileSdk = 36` and `targetSdk = 36`
   - `compose = true`

### Step 3: Compile & Install
- **Debug Build (Quick Testing):** Tap **Run (▶)** → **Run Debug · app**. CodeAssist will compile and prompt you to install `app-debug.apk`.
- **Release Build (Production APK):** Create or import a keystore in **Settings → Keystore Manager**, assign it under **`app` → Signing → `release`** (or keep `debug (default)` for personal testing—see **[SIGNING.md](SIGNING.md)** for full instructions), then run **Run Release · app**. The compiled APK is output to:
  ```text
  app/build/outputs/apk/release/app-release.apk
  ```

## Method 2: Build on PC (CodeAssist Desktop + Optional Emulator)

You can edit the source code in any PC text editor (VS Code, IntelliJ, Notepad++, etc.) and compile directly using **CodeAssist on Windows**.

### Step 1: Initialize the CodeAssist Project Folder
CodeAssist Desktop discovers projects located in:
```text
C:\Users\<YourUsername>\.codeassist\projects\
```
Because CodeAssist Desktop requires a `.platform/` metadata directory to list a project:
1. Open **CodeAssist Desktop** and create a blank **Jetpack Compose** project named `finvault` (this creates `C:\Users\<YourUsername>\.codeassist\projects\finvault\.platform`).
2. Close the project or open a terminal in `C:\Users\<YourUsername>\.codeassist\projects\finvault`.
3. Clone this repository into a temporary folder and copy its files (`app/`, `assets/`, `README.md`, `CHANGELOG.md`, `LICENSE`) into `C:\Users\<YourUsername>\.codeassist\projects\finvault`—**making sure you keep `.platform/`** and remove any default `app/src/main/java/` folder.

### Step 2: Build the APK
1. Re-open **`finvault`** inside **CodeAssist Desktop**.
2. Assign your keystore (or `debug (default)`) under **`app` → Signing → `release`** (see **[SIGNING.md](SIGNING.md)**), then run **Build / Run Debug · app** or **Build / Run Release · app**.
3. Locate your compiled APK at:
   - Debug: `app/build/outputs/apk/debug/app-debug.apk`
   - Release: `app/build/outputs/apk/release/app-release.apk`

### Step 3: Install on a Phone or Android Emulator via ADB
With **Android Platform Tools (`adb`)** installed and either a USB-debugging phone connected or an **Android Studio Virtual Device (AVD)** running:

```bash
adb devices
adb install -r app/build/outputs/apk/release/app-release.apk
```

## Method 3: Build in Android Studio (Gradle)

This repository intentionally omits Gradle wrapper and `.gradle.kts` files to stay lightweight for CodeAssist. If you prefer compiling in **Android Studio**, wrap the source files in a standard Empty Compose Activity project:

1. Open **Android Studio** → **New Project** → **Empty Activity (Jetpack Compose)**.
2. Set:
   - **Name:** `FinVault Yuri`
   - **Package name:** `com.yuri.finvault`
   - **Minimum SDK:** API 26 (Android 8.0)
3. Replace the generated files with the files from this repository:
   - Copy `app/src/main/kotlin/com/yuri/finvault/MainActivity.kt` into your Android Studio project's `app/src/main/java/com/yuri/finvault/MainActivity.kt` (replacing the default template `MainActivity.kt`).
   - Copy `app/src/main/AndroidManifest.xml` over your project's manifest.
   - Copy all folders inside `app/src/main/res/` (`drawable/`, `mipmap-*/`, `values/`) into your project's `app/src/main/res/`.
4. In your Android Studio `app/build.gradle.kts`, ensure:
   - `compileSdk = 36`, `targetSdk = 36`, `minSdk = 26`
   - Dependencies include `androidx.activity:activity-compose`, `androidx.compose.ui:ui`, `androidx.compose.foundation:foundation`, and `androidx.compose.material3:material3` (all included by default in Android Studio's Compose template).
5. Run **Build → Build Bundle(s) / APK(s) → Build APK(s)** or run directly via `./gradlew assembleDebug` / `./gradlew assembleRelease`.

## Troubleshooting

### "App not installed as package conflicts with an existing package"
Android enforces matching signing keys when upgrading an installed app. If you already installed an official APK downloaded from GitHub Releases and then build your own APK with a different keystore (or debug key):
1. Open **Settings → Offline Backup & Export → Copy Backup** in the existing app and save the JSON text safely.
2. Uninstall the previous build.
3. Install your self-built APK and use **Restore JSON → Paste** to restore all your records.

### Kotlin Redeclaration Errors
Ensure you do **not** have both `app/src/main/java/com/yuri/finvault/MainActivity.kt` and `app/src/main/kotlin/com/yuri/finvault/MainActivity.kt` at the same time. Only one `MainActivity.kt` should exist.

### Project Does Not Appear in CodeAssist Desktop
Confirm the project folder is inside `C:\Users\<YourUsername>\.codeassist\projects\finvault` (lowercase) and contains a valid `.platform/` folder generated by CodeAssist.
